# CHANGELOG（每次改动一条，顶部倒序追加）

> 条目必含：日期、范围、**验证方式与真实证据**、改动清单、涉及文件。
> 触发：bug 修复 / 新功能 / 重构 / 配置变更 / 设计文档变更 / 规则变更。豁免：纯文案 / 纯格式 / 纯注释。
> ⚠️ 写"已修复"之前必须 Read 被改文件确认落地；运行时类修复附真实运行证据。

格式示例：

```markdown
## YYYY-MM-DD · <会话名>

- fix: <一句话>（原因 / 影响范围）
  - 验证：<实际运行证据，如"curl 返回 200；端口检查输出 …">
  - 文件：<path1>, <path2>
```
