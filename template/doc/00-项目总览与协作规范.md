## 3. 多 AI 协作规范

### 3.1 规则与记忆的分层（重要，工具无关）

规则**正文只存一份**：根目录 `AGENTS.md`（跨 AI 工具事实标准）。各工具的加载情况：

| 工具 | 规则加载方式 | 说明（✅实测 ＞ 📄官方文档 ＞ ❓未验证） |
|---|---|---|

**去重铁律**：除 Trae 这类无引入机制的工具外，任何入口文件（CLAUDE.md 等）**禁止复制规则正文**，只允许一行引入——避免同一规则被多工具重复注入上下文、版本漂移。

**规则与记忆分离**：规则 = 强制指令（AGENTS.md，人工修订）；记忆 = 知识沉淀（`.workbuddy/memory/`，3000 字符限额，不承载规则）。

### 3.4 符号链接桥接（规则入口 / 跨工具记忆共享）

规则正文全项目只存一份（根目录 `AGENTS.md`），主流工具原生读取，**通常无需任何链接**。符号链接只在两种场景需要：

1. **权威源不在根目录**：规则因历史原因放在 `.codebuddy/rules/` 等工具目录时，在项目根建软链接让其他工具读到：
   ```cmd
   mklink AGENTS.md .codebuddy\rules\project-rules.md   :: 在项目根目录执行（相对路径目标）
   ```
2. **其他工具的全局记忆目录接入项目记忆**：各工具记忆目录在用户主目录下（项目外），把其中的索引/流水文件软链接到项目 `.workbuddy\memory\`，实现多工具共享同一份记忆。例（ZCode，在其记忆目录执行）：
   ```cmd
   mklink "C:\Users\<用户>\.zcode\cli\memories\projects\<项目ID>\memory\MEMORY.md" "<项目>\.workbuddy\memory\MEMORY.md"
   ```

**符号链接三坑（全部实测踩过）**：
- **Windows 建链需提权**：管理员 cmd，或开启开发者模式；`mklink` 是 cmd 内置命令，PowerShell 用 `New-Item -ItemType SymbolicLink`
- **跨机器共享盘必须用相对路径目标**：绝对路径（如 `K:\...`）会被客户端拿到本机解析，本机无该盘即读取失败；相对目标则随共享路径正确解析
- **git 仓库内符号链接可移植性差**：Windows 默认 `core.symlinks=false`，clone 后链接退化为含目标路径的文本文件——**项目内链接建议不入库**（按需生成），或团队统一 macOS/Linux 并 `core.symlinks=true`

**写入穿透限制**：ZCode / Claude Code 的 Edit/Write 工具**拒绝写穿符号链接**（官方行为）——AI 修改规则/记忆时必须直接编辑真实目标文件。因此链接文件只作"读入口"，正文权威路径要在规则中写明。

**记忆共享约定**：`.workbuddy/memory/` 是项目记忆唯一权威源；其他工具的全局记忆目录只放链接不放正文。`MEMORY.md` 为索引（各工具会话自动注入），日期流水文件按需读取；任一工具写入索引/流水即全工具可见（写穿同一权威文件）。

## 4. 质量与验证规范

### 4.1 修复落地验证（强制）

- CHANGELOG 记"已修复"前，必须 **Read 被修改文件**确认改动真实存在（不能只信编辑工具返回值）
- 运行时类修复必须**实际运行验证**，附真实证据；"语法检查通过"不算验证

### 4.2 修复验证方式对照表

| 修复类型 | 必须的验证方式 | 不充分的验证方式 |
|---|---|---|
| 纯逻辑 | 单测 / 静态追踪 | 仅肉眼看代码 |
| 进程/端口 | 实际启动 + 端口检查 | 仅语法检查 |
| HTTP API | 实际请求 | 仅语法检查 |
| 构建/部署 | 实际 build + 运行 | 仅看配置 |
| UI 交互 | 实际打开页面操作 | 仅 build 通过 |

### 4.3 回归预防

修复一处反模式后：① 检查其他文件有无同类问题；② 检查 CHANGELOG 有无"声称已修复但未验证落地"的同类条目。

## 5. 安全红线

- 凭据只进 `.env`（gitignored）；文档代码只写占位符
- 敏感数据不写入任何会外发的 prompt/请求体
- 禁止破坏性命令：`docker system prune -a`、裸路径递归删除、未经确认的批量删除
- 生产环境操作二次确认

## 6. 提交规范

- commit 格式：`<类型>: <摘要>`，类型 = feat/fix/docs/chore/refactor；中文摘要
- 每个逻辑单元一个 commit，不攒大包；推送前确认无凭据泄露
